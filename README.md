# Учебный тренажёр

Два предмета на одном сайте (переключатель в шапке):

- **Архитектура ЭВМ** — лекции, лабы с разбором, EWB-схемы, симуляторы и тесты по темам 1–9.
- **Программирование C++** (Borland C++Builder 6) — 15 тем по УМКД: лекции, лабы с онлайн-проверкой кода (эмулятор bcc32), эмулятор форм C++Builder, тесты-листалка.

Сайт: https://alantesterr.github.io/contents/
